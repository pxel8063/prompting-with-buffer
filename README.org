* Overview

=pwb= (Prompting with Buffer) is a lightweight Emacs client for Anthropic's
Claude API. It sends buffer contents as prompts and displays responses in a
dedicated =*Claude*= buffer. Conversation history is maintained per buffer, so
you can carry on multi-turn dialogues without leaving Emacs.

* Features

- Send the current buffer (or its narrowed region) as a prompt
- Synchronous and asynchronous request modes
- Per-buffer conversation history with save and restore
- Customizable model, token limit, and system prompt
- Fine-grained parameter control via =pwb-body-params=

* Prerequisites

- GNU Emacs 29.1 or later
- =curl= command-line tool installed and on your =PATH=
- An Anthropic API key (obtain one from [[https://console.anthropic.com][Anthropic Console]])

* Installation

** Clone the repository

#+begin_src bash
git clone https://github.com/pxel8063/prompting-with-buffer.git ~/.emacs.d/lisp/prompting-with-buffer
#+end_src

** Add to your init file

#+begin_src emacs-lisp
(add-to-list 'load-path "~/.emacs.d/lisp/prompting-with-buffer")
(require 'pwb)
#+end_src

** Configure your API key

=pwb= reads the API key from =auth-source=. Add an entry to your
=~/.authinfo= (or =~/.authinfo.gpg= for encrypted storage):

#+begin_example
machine api.anthropic.com password sk-ant-your-api-key-here
#+end_example

The =machine= value must match =pwb-api-host=, which defaults to
=api.anthropic.com=.

* Usage

** Basic workflow

1. Write or open text in an Emacs buffer.
2. Run =M-x pwb-current-buffer=.
3. View Claude's response in the =*Claude*= buffer.

If you want the buffer to remain responsive while waiting, use
=M-x pwb-async-current-buffer= instead.

** Commands

| Command                       | Description                                                  |
|-------------------------------+--------------------------------------------------------------|
| =pwb-current-buffer=          | Send the buffer (narrowed region if active) to Claude        |
| =pwb-async-current-buffer=    | Same as above, but asynchronous                              |
| =pwb-set-system-prompt=       | Set the system prompt to the current buffer's content        |
| =pwb-clear-system-prompt=     | Reset the system prompt to an empty string                   |
| =pwb-clear-conversation=      | Discard conversation history for the current buffer          |
| =pwb-save-conversation=       | Save conversation history to a file                          |
| =pwb-restore-conversation=    | Restore conversation history from a file                     |
| =pwb-print-assistant-turns=   | Re-print all assistant responses into the =*Claude*= buffer |

** Customizable variables

| Variable                 | Default                                   | Description                                |
|--------------------------+-------------------------------------------+--------------------------------------------|
| =pwb-model=              | ="claude-haiku-4-5"=                      | Claude model identifier                    |
| =pwb-max-tokens=         | =1024=                                    | Maximum tokens in the response             |
| =pwb-system-prompt=      | ="When possible, use org-mode syntax."=   | System prompt sent with every request      |
| =pwb-api-url=            | ="https://api.anthropic.com/v1/messages"= | Messages API endpoint URL                  |
| =pwb-api-host=           | ="api.anthropic.com"=                     | Machine name used for =auth-source= lookup |
| =pwb-anthropic-version=  | ="2023-06-01"=                            | Anthropic API version header               |

You can customise these interactively with =M-x customize-group RET pwb RET=,
or set them in your init file:

#+begin_src emacs-lisp
(setq pwb-model "claude-sonnet-4-5"
      pwb-max-tokens 2048)
#+end_src

** Per-buffer conversations

Each buffer maintains its own conversation history. When you call
=pwb-current-buffer= or =pwb-async-current-buffer=, a buffer-local copy of the
conversation state is created automatically. This means you can have
independent conversations running in different buffers simultaneously.

* Examples

** Sending a simple prompt

Open a buffer, type a prompt, and send it:

#+begin_example
Explain the difference between lexical and dynamic binding in Emacs Lisp.
#+end_example

Then run =M-x pwb-current-buffer=. The response appears in =*Claude*=.

** Setting a system prompt

Create a buffer with the system prompt you want:

#+begin_example
You are an expert Python developer. Provide concise,
efficient code with clear explanations.
#+end_example

Run =M-x pwb-set-system-prompt=. All subsequent requests will include this
system prompt until you change or clear it.

** Multi-turn conversation

1. Write your first prompt and run =pwb-current-buffer=.
2. Read the response in =*Claude*=.
3. In the same buffer, write a follow-up prompt below the original.
4. Narrow the buffer to only the follow-up text (=C-x n n=).
5. Run =pwb-current-buffer= again.

The conversation history from the first exchange is included automatically, so
Claude has full context.

** Controlling API parameters with =pwb-body-params=

The variable =pwb-body-params= lets you pass additional parameters to the
Claude Messages API. It is an alist that takes precedence over the customized
variables.

For example, to enable adaptive thinking, set up your buffer with file-local
variables:

#+begin_src org
  Explain why the sum of two even numbers is always even.


  # Local Variables:
  # pwb-model: "claude-opus-4-7"
  # pwb-max-tokens: 16000
  # pwb-body-params: ((thinking (type . "adaptive")))
  # pwb-system-prompt: ""
  # End:
#+end_src

Running =pwb-current-buffer= in this buffer produces a request equivalent to:

#+begin_example
curl https://api.anthropic.com/v1/messages \
     --header "x-api-key: $ANTHROPIC_API_KEY" \
     --header "anthropic-version: 2023-06-01" \
     --header "content-type: application/json" \
     --data \
'{
    "model": "claude-opus-4-7",
    "max_tokens": 16000,
    "thinking": {
        "type": "adaptive"
    },
    "messages": [
        {
            "role": "user",
            "content": "Explain why the sum of two even numbers is always even."
        }
    ]
}'
#+end_example

The precedence order for parameters, from highest to lowest, is:
=pwb-body-params=, then the customized variables (=pwb-model=,
=pwb-max-tokens=, =pwb-system-prompt=).
